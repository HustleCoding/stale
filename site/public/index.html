Stale indexes your whole disk once and sorts everything by when you last opened it. Find the forgotten gigabytes and move them to the Trash.

Download for Mac Free · macOS 12 or later · Apple silicon and Intel or brew tap hustlecoding/stale https://github.com/HustleCoding/stale && brew install --cask stale

By last use

Every folder sorted into this week, this month, last 6 months, over a year or never opened, using Spotlight's "last opened" dates.

Safe to clean up

Caches, build folders, duplicates, leftovers from deleted apps and old downloads. Everything goes to the Trash, never straight to deletion.

Fast and always current

Stale indexes once, then keeps up with changes in the background. It opens instantly, with no rescan on every launch.

Private by design

Stale only reads file sizes and dates. Nothing leaves your Mac: no account, no analytics.

Stale is free, with source on GitHub. Signed and notarized by Apple; updates install automatically. Release notes · Report a problem
